# Estansion

## Installation

To install Cursor, run the following command:

```bash
curl -fsSL https://downloads.cursor.com/origin/install.sh | sh
```

This will download and install Cursor on your system.

## Clone Omni-Lang Repository

To clone the Omni-Lang repository, run:

```bash
git clone https://origin.cursor.com/sandy-roy/omni-lang.git
```
